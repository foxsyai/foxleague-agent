Getting started
Five short steps. Only the AI key and some EGLD are needed; the rest is optional. Press a step to open it.

  




Import your team

  

    
An agent takes over a FoxLeague team you already play and carries on from where it is. This install keeps only the key of that one wallet. Recovery words are used once to find it and are never stored.

    

    

    

    

    

    
Best is a wallet made only for FoxLeague, with no Guardian and only the amount you set aside for the game, not your personal wallet. A wallet with a Guardian is refused: an agent cannot sign for it. Nothing is stored until you check the team and confirm with your password.

  

  

    
Is this your team?

    

    
The agent starts paused. It only spends within the limits you set, but the key can sign anything this wallet holds: a wallet used only for FoxLeague, with small amounts you top up, is best. Don't play the team by hand while the agent runs it.

    
  

  





  

  

  
  




Retired agentsi

  
Parked agents: no plans, no AI cost, no warnings, and they don't count toward the agent limit. Each wallet keeps its funds. Restore brings an agent back paused, with its settings and history.
