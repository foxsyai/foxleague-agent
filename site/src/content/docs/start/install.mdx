import { CardGrid, LinkCard } from '@astrojs/starlight/components';

The agent runs on your own computer, so your wallet and keys never leave it. One line starts a guided installer
on Windows, on a Mac and on Linux. Pick your system: its page has the line to paste, what you will see step by
step, how to update and uninstall and what to do if it gets stuck. The computer has to stay on and awake for the
agent to play; a small cloud server works too ([Run it on a server](/help/server/)).
