The agent runs on your own computer, so your wallet and keys never leave it. It works on **Linux**, **macOS**
and **Windows through WSL2**. The computer has to stay on for the agent to play; a small cloud server works too
([Run it on a server](/help/server/)).

## Before you start

- About **5 EGLD** to send to your agent later (you can install first and fund it after).
- About 5 minutes to create your **AI key** at Anthropic ([Your keys](/start/keys/)). You can also add it after
  the install.
- Install as a user of your own, not as root: as root the installer stops and tells you to create a user first
  (`adduser fox`, then `su - fox` and paste the line).

## Install

<ComingSoon>

<Tabs>
	<TabItem label="Linux and macOS">
		Open a terminal and paste this line:

		```sh
		curl -fsSL https://raw.githubusercontent.com/foxsyai/foxleague-agent/main/get.sh | bash
		```

		On Ubuntu, install curl first, because Ubuntu Desktop comes without it: `sudo apt install curl`. Use this
		one, not the snap that Ubuntu's hint offers: the apt one is the one the install is tested with. macOS has
		curl already.

		On Linux the agent keeps running after you log out and after a restart. On macOS the agent starts when you
		log in, and a sleeping Mac plays nothing: set the Mac not to sleep while the agent should play.
	</TabItem>
	<TabItem label="Windows">
		Open **Windows PowerShell** (Start, type PowerShell) in a normal window, not "as administrator", and paste
		this line:

		```powershell
		irm https://raw.githubusercontent.com/foxsyai/foxleague-agent/main/get.ps1 | iex
		```

		It needs 64-bit Windows 11 or Windows 10 version 2004 or later. On Windows the agent runs inside
		**Ubuntu**, a Linux that Windows itself runs (WSL2). The line sets that up where it is missing and then
		starts the same installer as on Linux. It is safe to paste it again at any time: each run finds what is
		already done and goes on from there. What it does and what it asks:

		<Steps>
		1. **WSL.** When Windows does not have it yet, the installer runs Microsoft's own
		   `wsl --install --no-distribution`. That needs an administrator, so Windows shows its own prompt: answer
		   Yes. When Windows then needs a restart, the installer says so: restart, open PowerShell again and paste
		   the same line.
		2. **Ubuntu.** When it is not installed yet, it is downloaded. The download can look stuck at 0%: a click
		   into the PowerShell window pauses it (Windows then selects text), and Enter once lets it go on. A window
		   "Welcome to WSL" may open by itself: close it. Ubuntu then asks you to choose a Linux
		   username and password, in the same window or in a window of its own. They are new and yours to choose:
		   they are not your Windows login and the installer never sees them. Nothing shows while you type the
		   password. Ubuntu may also ask "Help improve Ubuntu!" (Y/n/e): either answer is fine for the agent. When
		   Ubuntu then shows its own prompt (a line that ends with `$`), type `exit` to come back to the installer.
		3. **systemd and curl.** The installer turns on systemd in Ubuntu's `/etc/wsl.conf`, restarts Ubuntu once
		   and installs curl when it is missing. If you already use this Ubuntu, it asks before the restart.
		4. **The agent's installer.** The same seven steps as on Linux, in the same window
		   ([What the installer asks](#what-the-installer-asks)).
		5. **Keeping the agent running.** The installer makes a scheduled task of your Windows user, called
		   "FoxLeague Agent (WSL)". Then it shows the dashboard address.
		</Steps>

		**The dashboard** is at `http://localhost:8870` in your Windows browser (or at the port you chose): the last
		screen shows the address and offers to open it.

		**When it plays.** On Windows the agent runs while Ubuntu (WSL) runs. By itself, closing the last Ubuntu
		window may stop it after a short while and Ubuntu does not start with Windows. The scheduled task is there
		to keep Ubuntu running for as long as you are logged in to Windows, with every window closed. The agent
		does not play while the PC is off or asleep and not before you log in after a restart. If it stops although
		you are logged in, see [Troubleshooting](/help/troubleshooting/). For an agent that plays every day
		without your PC, use a small server ([Run it on a server](/help/server/)).

		**Its files** are inside Ubuntu, in `~/foxleague-agent`. From Windows Explorer that folder is
		`\\wsl$\Ubuntu\home\<your Linux username>\foxleague-agent`. The commands of these pages that start with
		`./` or `systemctl` are typed inside Ubuntu: open it with `wsl -d Ubuntu --cd ~` in PowerShell.

		**Update and uninstall.** An update is one click in the dashboard, as on every system
		([Update](/help/update/)). To uninstall, see [Uninstall](/help/update/#uninstall): one command inside
		Ubuntu and one in PowerShell.

		**By hand**, without the PowerShell line:

		<Steps>
		1. In PowerShell opened as administrator, run `wsl --install -d Ubuntu`. Restart Windows if it asks.
		2. Open Ubuntu from the Start menu. The first time, it asks for a Linux username and password.
		3. Turn on systemd, which runs the agent in the background. Run `cat /etc/wsl.conf`. If it says
		   `systemd=true` under `[boot]`, go to the next step. If it has no `[boot]` line, run
		   `sudo sh -c 'printf "\n[boot]\nsystemd=true\n" >> /etc/wsl.conf'`. If it has a `[boot]` line, open the
		   file with `sudo nano /etc/wsl.conf` and make the line under it read `systemd=true` (change a
		   `systemd=false` or add the line). Do not add a second `[boot]`: WSL takes the first `systemd` line it
		   finds. Then close Ubuntu, run `wsl --shutdown` in PowerShell and open Ubuntu again.
		4. If `curl --version` says that curl is not found, run `sudo apt install curl`.
		5. Paste the Linux line in Ubuntu:

		   ```sh
		   curl -fsSL https://raw.githubusercontent.com/foxsyai/foxleague-agent/main/get.sh | bash
		   ```
		</Steps>

		Installed by hand, nothing keeps Ubuntu running: leave an Ubuntu window open (minimised is fine) for as
		long as the agent should play. Or paste the PowerShell line once: it keeps your install and adds the
		scheduled task.
	</TabItem>
</Tabs>

The line downloads the newest release into `~/foxleague-agent`, checks the download against the release's checksum
and starts the guided installer. To install a given version, put it in front:
`curl -fsSL .../get.sh | FOXAGENT_VERSION=vX.Y.Z bash`. An older version is not put over a newer install: add
`FOXAGENT_ALLOW_DOWNGRADE=1` in front of `bash` to go back anyway (the settings and limits the newer version added
are then not applied). Another folder is named with `FOXAGENT_DIR`; it must be empty or hold an install of
foxleague-agent.

On Windows the same switches are set in PowerShell before the line, for example
`$env:FOXAGENT_VERSION = 'vX.Y.Z'`. `FOXAGENT_DIR` then names a folder inside Ubuntu, never a Windows folder.

## What the installer asks

It walks you through seven short steps and explains each one:

| Step | What happens |
|---|---|
| 1. Node.js | Uses the Node.js on your computer when the agent runs on it (22 from 22.18, or 24.2 and later, with npm beside it), otherwise downloads a private copy and checks it against the SHA-256 written in the installer. |
| 2. Wallet | Creates a new wallet for your first agent and shows its **recovery words once**. Write them on paper. |
| 3. Dashboard login | You choose a user name, a password (12 characters or more) and a port (8870 by default). There is no default username: Enter alone is refused. A password that is too short or typed differently the second time is asked for again. A port that another program already uses is refused and the next one is offered. |
| 4. Keys | The AI key, Telegram and the CEX top-up, each with simple steps and links. You can skip any of them. |
| 5. Settings | Agents start in **dry run**. You choose whether this computer may sign real transactions once you press Go LIVE. |
| 6. PEM files | Writes `pem/agent1.pem`, so you can log into the FoxLeague app as your agent's team and watch it play. |
| 7. Background service | Starts the agent in the background. On Linux it keeps running after you log out and after a restart. On macOS it starts when you log in. On Windows it runs while Ubuntu (WSL) runs: the scheduled task of the Windows installer is there to keep Ubuntu running while you are logged in. |

<Aside type="caution" title="Your recovery words">
The words are the only way to recover your agents' wallets. Keep them on paper, offline. Anyone with them controls
the wallets. Never type them into a website, a chat or a screenshot. To see them again, run
`./cli.sh backup-words` in the `foxleague-agent` folder, in your own terminal. Until you have typed `yes` at "Type
yes when the words are written down", every run of the installer shows them and asks again.
</Aside>

Run the installer again at any time (`./install.sh` in the `foxleague-agent` folder): it keeps your wallet, login and keys.
It asks again for the port, the keys and the live permission, each with your earlier answer as the default.
At "Enter keys now?" Enter means no on every later run: the keys stay as they are, and you change them in the
dashboard. Pressing Enter at the live permission keeps it as `.env` has it: on only when it already says 1 or true.

## After the install

Open **http://localhost:8870** and log in. The installer's last screen shows that address as a link (in most
terminals: hold Ctrl and click it; on a Mac, Cmd) and, on a computer with a desktop, offers to open it in your
browser. The **Getting started** guide opens by itself and shows what is left: your keys, funding your agent and
going live. Next: [Your keys, step by step](/start/keys/).

The dashboard may be open in two browsers, for example a tab inside an editor and your default browser. Each has
its own sign-in, so the page the installer opens can ask for the login although another tab is signed in.

When a new version is out, the dashboard tells you and installs it with one click ([Update](/help/update/)).
