## Fund your agent

The agent pays the game in FOXSY and network fees in EGLD. You send EGLD; it buys the FOXSY it needs by itself on
xExchange.

<Steps>
1. Buy EGLD on any exchange (for example Binance, Bybit or Bitget).
2. Withdraw it to the **wallet of agent 1** on the **MultiversX (EGLD)** network. The address is on the agent's
   page, in **Wallet and team**, with a Copy button. The installer printed it too.
3. About **5 EGLD** is a good start: 2.5 buys the 5,000 FOXSY registration, 1 stays as the gas reserve, the rest
   plays the first games.
</Steps>

There is no need to send more at once. The agent's wallet is a wallet only for the game: keep small amounts in it
and top it up daily, weekly or whenever it suits you.

Once the EGLD arrives and you have gone live, the agent registers your team by itself: it swaps for the
registration fee, picks a name, registers and generates the team's free badge.

A dry run buys nothing, so a new wallet shows only the first of these steps there. The plan shows the simulated
swap; the registration line then says it needs 5,000 FOXSY for the fee, because nothing was really bought. A
later plan of the same game day may refuse the swap too and name the daily swap allowance, because the simulated
swap is counted for that day. Both are expected: the team is registered after Go LIVE.

## Watch it in dry run

New agents start in **dry run**: the agent plans, checks each action against the game rules and your limits, then
**simulates** it on chain. Nothing is signed or sent. Read a plan or two in **Last plan** and **Activity**; every
action shows what it would have done and cost (or why it was refused). An action that needs what an earlier one
would have bought is refused in dry run, as the registration of a new wallet is (above). A fusion that makes a new
card is checked and its cost counted, but not simulated: FoxLeague prepares that transaction only for a real fusion,
so its own checks of the cards come into play only after Go LIVE.

Meanwhile, set your **limits** and **strategy** in **Settings** ([Every setting explained](/use/settings/)).

## Go live

<Steps>
1. Press **Go LIVE** in the header.
2. Type `GO LIVE`, then your dashboard password.
3. The agent now signs real transactions, inside the same limits.
</Steps>

![The Go LIVE dialog: type GO LIVE and your password](/screenshots/go-live.png)

<Aside>
Back to dry run is one click. The **Kill switch** stops every agent at once; **Pause** stops one agent. Your funds,
settings and strategy stay as they are.
</Aside>

Live also needs this computer's permission, which the installer asked for (step 5). If Go LIVE is grey, allow it:
set `AGENT_LIVE_ENABLED=1` in the `.env` file in the `foxleague-agent` folder and restart the agent.
