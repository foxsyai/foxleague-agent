The agent needs one key to play: the **AI key**. Telegram and the CEX top-up are optional. You can paste each key in the
installer, or later in the dashboard: **Keys** in the header. Your dashboard password confirms every change.

![The Getting started guide in the dashboard: each step shows done, needed or optional](/screenshots/getting-started.png)

## 1. The AI key (Anthropic), needed

This is the AI that plans for your agents. Without it they only watch.

<Steps>
1. Open [platform.claude.com](https://platform.claude.com) and sign up, or log in.
2. Open [Billing](https://platform.claude.com/settings/billing) and add credit. $10 runs a single agent at the
   defaults for about two weeks.
3. Open [Limits](https://platform.claude.com/settings/limits) and set a monthly spend limit, for example $60: a
   month of a single agent at the defaults with room to spare. Then it can never cost more than that. When the
   limit is reached (or the credit runs out, or the key stops working) you hear it once on Telegram; one agent then
   asks again at each of its plans and the others wait without reading anything, and you hear once more when plans
   work again. **Plan now** always asks.
4. Open [API keys](https://platform.claude.com/settings/keys), press **Create key**, name it `foxleague-agent` and
   copy it. It is shown only once.
5. In the dashboard, press **Keys**, paste it into **Anthropic API key**, type your dashboard password and press
   **Save**. The agent uses it at once.
</Steps>

About $0.60 a day for a single agent with the default model, effort and tick (Haiku 5.5 at high, a plan every 2 hours inside 12 active hours, about $0.10 a plan): every plan sends the rules and the game manual, about 105,000 tokens, and they are cached for an hour only when another plan comes within that hour, so a lone agent sends them at the plain price. Agents that plan within the same hour share the cache and pay far less for that text: measured on real plans, ten agents on Opus 5.5 at high effort averaged $0.15 a plan with the manual from the cache and $0.60 without. Sonnet, Opus, Fable and a higher effort cost more for the same plan, and a shorter tick means more plans a day. You pick the model and effort in the Strategist box.

## 2. Telegram, optional

A summary of every agent each morning and any detail on request; you can also talk to your manager in plain words.

<Steps>
1. On your phone, open Telegram and start a chat with [BotFather](https://t.me/BotFather). It creates your
   agent's Telegram account.
2. Send `/newbot`. Give it a name, then a username. Telegram requires the username to end in "bot", for example
   `myfox_manager_bot`.
3. BotFather answers with a token that looks like `123456789:AAH...`. Copy it.
4. In the dashboard, press **Keys**, paste it into **Telegram token**, type your password and press **Save**.
5. Still in Keys, press **Link my Telegram**. Send the 6-digit code it shows to your agent's Telegram account,
   then press **I sent it**. From then on it talks only to you.
</Steps>

## 3. CEX top-up, optional

For EGLD top-ups of your agent wallets from an exchange (a CEX), so you do not have to send EGLD by hand. You
approve each one. When an agent runs low, Telegram shows what it has, its warning level, the EGLD that brings it
to its monthly budget and a one-time code. Send `/topup` with the code and Binance sends the EGLD to that agent's
own wallet (`/topup 482193 10` withdraws 10 EGLD instead, less than proposed (Binance's fee comes off that)). `/topup 2` asks for a top-up of agent 2 at any time. The
code works once, for an hour. It needs Telegram and LIVE mode.

An account in the EU is asked a short Travel Rule form with each withdrawal; the agent fills it in for a
withdrawal to your own wallet, once you set `BINANCE_ACCOUNT_TYPE=individual` (or `corporate` for a company
account) in the `.env` file and restart.

The example is Binance: an API key that can only read your account and withdraw EGLD to your agent wallets.

<Steps>
1. Log in to Binance and open [API Management](https://www.binance.com/en/my/settings/api-management).
2. Press **Create API**, choose **System generated**, name it `foxleague-agent` and confirm with your 2FA.
3. Press **Edit restrictions**. Tick only **Enable Withdrawals**, then choose **Restrict access to trusted IPs**
   and enter the public IP of the computer the agent runs on ([shown here](https://api.ipify.org) when you open
   it there).
4. Open [Address Management](https://www.binance.com/en/my/security/address-management), add each agent wallet on
   the **MultiversX (EGLD)** network and switch the whitelist on. Now money can only go to your agents. A top-up
   goes only to a wallet on this whitelist, and **Test keys** shows which agent wallets are not on it yet.
5. Copy the API key and the secret (the secret is shown only once). In the dashboard, press **Keys**, paste both,
   type your password and press **Save**.
</Steps>

<Aside type="caution">
Never tick trading or transfers on the Binance key. If your internet provider changes your IP, update it on
Binance.
</Aside>

**Test keys** in the Keys panel checks every key: model access for the AI key, a test message to your Telegram
chat and the permissions of the Binance key. Nothing is changed.
